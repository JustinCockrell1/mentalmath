Mental Math Trainer
Overview
Mental Math Trainer is a web application designed to help users improve their mental arithmetic skills. The app provides various levels of multiplication problems, including 2x2, 2x3, and more. It's perfect for students, math enthusiasts, or anyone looking to sharpen their math skills.

The project is built using TypeScript, ensuring type safety and maintainability, making it a reliable and scalable solution.

Features
Multiple levels of multiplication challenges:
2x2 multiplication
2x3 multiplication
Customizable problem sets
User-friendly interface designed for quick mental calculations
Instant feedback on your answers
Track your performance over time to measure improvement
